# 🎬 Movie Recommendation System

A Machine Learning-powered Movie Recommendation System that suggests movies based on user preferences using content-based filtering techniques. The system analyzes movie metadata such as genres, keywords, cast, and overview to recommend similar movies, helping users discover films tailored to their interests.

---

## 🚀 Features

* 🎥 Personalized movie recommendations
* 🔍 Content-based filtering using movie metadata
* 📊 Similarity calculation using Cosine Similarity
* 🧹 Data preprocessing and feature engineering
* ⚡ Fast and efficient recommendation generation
* 🖥️ Simple and user-friendly interface

---

## 🛠️ Tech Stack

* **Python**
* **Pandas**

* **NLTK**

## 📂 Project Workflow

1. Data Collection and Loading
2. Data Cleaning and Preprocessing
3. Feature Extraction
4. Text Vectorization using CountVectorizer
5. Similarity Matrix Generation using Cosine Similarity
6. Recommendation Engine Development
7. Movie Recommendation Output

---

## 📊 Dataset

The project utilizes movie datasets containing:

* Movie Title
* Genres
* Keywords
* Cast
* Crew
* Overview
* Popularity Ratings

Dataset Source: TMDB Movie Dataset

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/movie-recommendation-system.git
```

Navigate to the project directory:

```bash
cd movie-recommendation-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

## 💡 Example

```python
recommend("Avatar")
```
